## Model Answer

### 直接答案

呢組欄位控制 Branded App 嘅背景圖、描述、聯絡資料、社交及網站連結、商店連結同專用條款。

**出現位置：** CMS → Company → Company Groups → Branded App；內容主要顯示喺 Branded App 或相關 Web 頁面。

### 已確認欄位

| Field | 必填程度 | 建議填寫／Default | 用途／影響 | 操作注意事項 | 來源頁 |
|---|---|---|---|---|---|
| **Background Image** | 選填 | App 背景圖 | Branded App 顯示 | Branded App 先需要 | P.10 |
| **Group Description (English)** | 選填 | 英文簡介 | App / Web 描述 | 如有前台展示先填 | P.10 |
| **Group Description (Local Language)** | 選填 | 中文簡介 | App / Web 中文描述 | 如有前台展示先填 | P.10 |
| **Branded App Link** | 選填 | App link | 導向 branded app | Branded App 先需要 | P.10 |
| **Email** | 選填 | CS / merchant email | 前台聯絡資料 | 如前台有顯示先填 | P.10 |
| **Facebook** | 選填 | Facebook URL | 前台 social link | 需完整 URL | P.10 |
| **Instagram** | 選填 | Instagram URL | 前台 social link | 需完整 URL | P.10 |
| **Url** | 選填 | Website URL | 前台 website link | 需完整 URL | P.10 |
| **About Us Url** | 選填 | About Us URL | 前台 About Us 連結 | Branded App / Web 先需要 | P.10 |
| **How To Use Url** | 選填 | How To Use URL | 前台教學連結 | 可留空 | P.10 |
| **EStore Url** | 選填 | E-shop URL | 導向網店 | 有 eShop 先填 | P.10 |
| **Branded App Terms and Conditions** | 視乎需要 | HTML 格式 | Branded App T&C | Branded App 先需要 | P.10 |

### 操作前注意

- Branded App 上線前要核對 Background Image、Email 同專用 Terms and Conditions。
- 所有外部連結應使用正式網址並先測試開啟結果。
- 如果實際 CMS 畫面同呢份已確認資料不一致，停止推斷並交由內容負責人覆核。
