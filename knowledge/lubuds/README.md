# LUBUDS Model Answers

呢個資料夾將 LUBUDS 專案 WhatsApp 對話整理成可重用嘅支援答案。

## 收錄原則

- 只保留已在對話中有明確處理方法或結論嘅主題。
- 移除人名、電話、電郵、會員 ID、交易編號、密碼、API key、測試卡資料及附件內容。
- 原始 WhatsApp 匯出、圖片、錄音、影片、試算表及壓縮檔不會提交到 repository。
- 個別客戶補數、補券或改資料只可作排查例子，唔會寫成通用自動操作。
- 涉及會員、積分、優惠券、交易、權限或正式環境嘅答案均標示為高風險。

## 使用方式

同事應先用對應答案做初步排查，再收集必要而最少量嘅資料交畀技術團隊。任何會改動會員權益或正式環境設定嘅操作，都要先取得授權並保留審計紀錄。

## 來源

內容由三個私人 WhatsApp 群組匯出整理：LUBUDS x Storellet、Lubuds x GoPOS x Storellet，以及 Inline x LUBUDS App。原始來源只供離線覆核，不屬於知識庫內容。
