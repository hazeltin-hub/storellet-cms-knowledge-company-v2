# ⚙️ AI 設置面板使用指南

## 概述

AI 設置面板已整合到 chatroom 中，無需再編輯 `config.js` 文件。所有設置都可以通過用戶界面完成。

## 訪問設置面板

### 方法 1：通過 Chatroom

1. 開啟 Chrome Extension
2. 點擊右上角的 **⚙️** 按鈕
3. 設置面板會從右側滑入

### 方法 2：重新載入後

如果設置面板未顯示：
1. 重新載入 Extension
2. 刷新 Side Panel

## 設置選項說明

### 1. Claude API Key

**輸入格式：** `sk-ant-xxxxx...`

**如何獲取：**
1. 點擊輸入框下方的鏈接
2. 前往 [Anthropic Console](https://console.anthropic.com/)
3. 登入或創建帳戶
4. 前往 "API Keys" 頁面
5. 點擊 "Create API Key"
6. 複製 API Key（只顯示一次，請妥善保存）

**驗證：**
- ✅ 必須以 `sk-ant-` 開頭
- ✅ 系統會自動檢測格式錯誤
- 🔒 顯示為密碼格式（•••••）

### 2. AI 模型選擇

**選項：**

| 模型 | 特點 | 成本 | 推薦用途 |
|------|------|------|----------|
| **Claude Sonnet** | 最佳質量，推理能力強 | ~$1.35/100次 | 生產環境，重要問題 |
| **Claude Haiku** | 經濟實惠，速度快 | ~$0.11/100次 | 測試，一般查詢 |

**選擇建議：**
- 第一次使用：選 Sonnet 體驗最佳效果
- 成本敏感：選 Haiku
- 不確定：選 Sonnet，後續可調整

### 3. 最大答案長度 (Max Tokens)

**範圍：** 100 - 4000 tokens
**預設：** 1000 tokens

**參考值：**
- `500`：簡短答案，適合快速查詢
- `1000`：標準答案（推薦）
- `2000`：詳細答案，適合複雜問題
- `4000`：非常詳細的答案

**說明：**
- 1 token ≈ 4 個英文字或 2 個中文字
- 設置過長可能浪費成本
- 設置過短可能答案不完整

### 4. 創造性程度 (Temperature)

**範圍：** 0.0 - 1.0
**預設：** 0.7

**效果：**
- `0.3`：保守，答案一致性强
- `0.7`：平衡（推薦）
- `1.0`：有創造性，但可能不穩定

**建議：**
- CMS 問答建議 0.3-0.7
- 創造性任務可用 0.8-1.0

### 5. 啟用 AI 功能

**功能：**
- ✅ 勾選：找不到 model answer 時使用 AI
- ❌ 不勾選：只使用 model answer

**建議：**
- 初次使用時測試後再啟用
- 確保 API Key 正確後啟用

## 設置步驟

### 第 1 步：打開設置面板

點擊右上角的 **⚙️** 按鈕

### 第 2 步：輸入 API Key

1. 點擊 "前往 Anthropic Console" 獲取 API Key
2. 將 API Key 粘貼到輸入框
3. 確認格式正確（sk-ant- 開頭）

### 第 3 步：選擇設置

1. 選擇模型（推薦 Sonnet）
2. 設置最大答案長度（推薦 1000）
3. 調整創造性程度（推薦 0.7）

### 第 4 步：測試連接

1. 點擊 **🔍 測試連接** 按鈕
2. 等待測試結果
3. 確認顯示 "✅ API 連接成功！"

### 第 5 步：保存設置

1. 勾選 **啟用 AI 功能**
2. 點擊 **💾 儲存設置** 按鈕
3. 確認顯示 "✅ 設置已儲存！"
4. 點擊 **✕** 關閉設置面板

## 使用統計

設置面板底部顯示使用統計：

| 統計項 | 說明 |
|--------|------|
| **AI 搜索次數** | 總共調用 AI 的次數 |
| **成功找到答案** | AI 成功找到相關資訊的次數 |
| **API 使用量** | 估計的 token 使用量 |

## 故障排除

### 問題：設置面板無法打開

**解決方法：**
1. 重新載入 Extension
2. 檢查瀏覽器 Console 是否有錯誤
3. 刷新 Side Panel

### 問題：測試連接失敗

**可能原因：**
1. API Key 格式錯誤
2. API Key 過期或無效
3. 網絡連接問題

**解決方法：**
1. 確認 API Key 以 `sk-ant-` 開頭
2. 重新生成 API Key
3. 檢查網絡連接

### 問題：AI 沒有啟動

**檢查清單：**
- [ ] 已勾選 "啟用 AI 功能"
- [ ] API Key 已正確輸入
- [ ] 點擊 "儲存設置"
- [ ] 重新載入問題測試

**調試方法：**
1. 打開瀏覽器 Console
2. 搜索問題
3. 查看 AI 相關日誌

### 問題：設置沒有保存

**解決方法：**
1. 檢查 Chrome storage 權限
2. 重新輸入並保存
3. 查看 Console 是否有錯誤

## 安全建議

1. **API Key 保護：**
   - 🔒 不要分享 API Key
   - 🔄 定期更換 API Key
   - 👤 只在個人設備上使用

2. **成本控制：**
   - 📊 定期檢查使用統計
   - 💰 設置使用限額
   - 🔄 考慮使用 Haiku 節省成本

3. **數據隱私：**
   - ✅ 設置保存在本地
   - ✅ 不會上傳到雲端
   - ✅ 可隨時清除

## 進階功能

### 重置設置

如果需要重置所有設置：

1. 打開 Chrome DevTools Console
2. 輸入：
```javascript
chrome.storage.local.remove('aiSettings')
```
3. 重新載入 Extension

### 導出設置

查看當前設置：

1. 打開 Chrome DevTools Console
2. 輸入：
```javascript
chrome.storage.local.get('aiSettings', console.log)
```

### 手動設置

通過 Console 直接設置：

```javascript
chrome.storage.local.set({
  aiSettings: {
    apiKey: "sk-ant-your-key",
    model: "claude-3-5-sonnet-20241022",
    maxTokens: 1000,
    temperature: 0.7,
    enabled: true
  }
})
```
