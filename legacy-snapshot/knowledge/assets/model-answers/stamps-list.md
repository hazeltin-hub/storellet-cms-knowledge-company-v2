## Model Answer

**List all Stamps** 顯示所有印花（Stamps）嘅列表資料。

### 顯示欄位

1. **Stamp ID**：顯示 Stamp 唯一識別碼
2. **Brand**：顯示所屬品牌
3. **Stamp Name**：顯示印花名稱
4. **Required Count**：顯示所需印花數量
5. **White Label**：顯示是否只限 White Label App
6. **Status**：顯示當前狀態（Active / Inactive）
7. **Edit**：編輯 Stamp 設定
8. **Export**：匯出 Stamp 資料

### 頁面用途

- 查看現有印花設計
- 管理印花數量和獎勵
- 編輯印花設定
- 匯出資料做分析

## 注意事項

- Required Count 決定用戶需要幾多個印花可以兌換獎勵
- 所有顯示欄位由 Create new Stamp 頁面嘅設定決定
- 可以按 Brand、Status 等條件篩選顯示
