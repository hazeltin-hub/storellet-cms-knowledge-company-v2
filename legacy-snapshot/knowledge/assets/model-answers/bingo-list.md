## Model Answer

**Bingo List** 顯示所有賓果遊戲（Bingo）嘅列表資料。

### 顯示欄位

1. **Bingo ID**：顯示 Bingo 遊戲唯一識別碼
2. **Brand**：顯示所屬品牌
3. **Bingo Name**：顯示遊戲名稱
4. **Start Date**：顯示活動開始日期
5. **End Date**：顯示活動結束日期
6. **White Label**：顯示是否只限 White Label App
7. **Status**：顯示當前狀態（Active / Inactive）
8. **Edit**：編輯 Bingo 遊戲
9. **Export**：匯出 Bingo 資料

### 頁面用途

- 查看現有賓果遊戲活動
- 管理遊戲狀態和有效期
- 編輯遊戲設定
- 匯出資料做分析

## 注意事項

- 所有顯示欄位由 Create new Bingo 頁面嘅設定決定
- Bingo ID 係唯一識別碼，用於記錄和參考
- 可以按 Brand、Status 等條件篩選顯示
