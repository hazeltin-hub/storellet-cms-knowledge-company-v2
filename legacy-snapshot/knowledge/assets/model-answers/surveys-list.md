## Model Answer

**Surveys List** 顯示所有問卷調查（Surveys）嘅列表資料。

### 顯示欄位

1. **Survey ID**：顯示問卷唯一識別碼
2. **Brand**：顯示所屬品牌
3. **Survey Name**：顯示問卷名稱
4. **Question Count**：顯示問題數量
5. **Start Date**：顯示開始日期
6. **End Date**：顯示結束日期
7. **Response Count**：顯示回應數量
8. **Status**：顯示當前狀態（Active / Inactive）
9. **Edit**：編輯問卷設定
10. **Export**：匯出問卷資料

### 頁面用途

- 查看現有問卷調查
- 监控問卷回應情況
- 管理問卷狀態和有效期
- 編輯問卷內容

## 注意事項

- Question Count 顯示問卷包含幾多條問題
- Response Count 顯示有幾多用戶已經回應
- 可以按 Brand、Status 等條件篩選顯示
- 所有顯示欄位由 Create Survey 頁面嘅設定決定
