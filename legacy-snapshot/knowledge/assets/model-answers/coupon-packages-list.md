## Model Answer

**Coupon Packages List** 顯示所有優惠券套裝（Coupon Packages）嘅列表資料。

### 顯示欄位

1. **Package ID**：顯示套裝唯一識別碼
2. **Brand**：顯示所屬品牌
3. **Package Name**：顯示套裝名稱
4. **Coupon Count**：顯示包含優惠券數量
5. **Package Price**：顯示套裝價格
6. **Start Date**：顯示開始日期
7. **End Date**：顯示結束日期
8. **Status**：顯示當前狀態（Active / Inactive）
9. **Edit**：編輯套裝設定
10. **Export**：匯出套裝資料

### 頁面用途

- 查看現有優惠券套裝
- 管理套裝組合和價格
- 監控套裝銷售和使用情況
- 編輯套裝設定

## 注意事項

- Coupon Count 顯示套裝包含幾多張優惠券
- Package Price 係購買套裝所需價格或積分
- 所有顯示欄位由 Create Coupon Package 頁面嘅設定決定
