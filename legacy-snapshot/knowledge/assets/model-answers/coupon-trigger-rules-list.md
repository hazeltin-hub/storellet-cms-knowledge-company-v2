## Model Answer

**Coupon Trigger Rules List** 顯示所有優惠券觸發規則嘅列表資料。

### 顯示欄位

1. **Rule ID**：顯示規則唯一識別碼
2. **Rule Name**：顯示規則名稱
3. **Trigger Type**：顯示觸發類型
4. **Trigger Event**：顯示觸發事件
5. **Coupon ID**：顯示關聯嘅優惠券
6. **Status**：顯示當前狀態（Active / Inactive）
7. **Edit**：編輯規則設定
8. **Export**：匯出規則資料

### 頁面用途

- 查看現有觸發規則
- 管理自動發放優惠券規則
- 監控規則運作狀態
- 編輯觸發條件

## 注意事項

- Trigger Type 決定觸發方式（如註冊、生日、消費）
- Trigger Event 係具體嘅觸發事件
- Coupon ID 關聯到要發放嘅優惠券
- 規則用於自動化優惠券發放流程
