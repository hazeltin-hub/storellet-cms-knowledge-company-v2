## Model Answer

**Assets tab** 係 CMS 用嚟管理所有會員獎勵資源嘅主要功能區。

### Assets tab 功能概覽

Assets tab 包含以下 8 種資產類型嘅管理功能：

#### 1. **Points（積分獎品）**
- **Points List**：顯示所有積分獎品列表
- **Create new Points**：創建新積分獎品（如 Welcome Pack、Birthday Gift）

#### 2. **Discount Cards（折扣卡）**
- **Discount Cards List**：顯示所有折扣卡列表
- **Create Discount Cards**：創建新折扣卡（如 Basic、Silver、Gold 等級）

#### 3. **Bingo（賓果遊戲）**
- **Bingo List**：顯示所有賓果遊戲列表
- **Create new Bingo**：創建新賓果遊戲活動

#### 4. **Stamps（印花卡）**
- **List all Stamps**：顯示所有印花卡列表
- **Create new Stamp**：創建新印花卡設計

#### 5. **Coupons（優惠券）**
- **Coupons List**：顯示所有優惠券列表
- **Create Coupon**：創建新優惠券

#### 6. **Coupon Packages（優惠券套裝）**
- **Coupon Packages List**：顯示優惠券套裝列表
- **Create Coupon Package**：創建優惠券套裝組合

#### 7. **Coupon Trigger Rules（優惠券觸發規則）**
- **Coupon Trigger Rules List**：顯示觸發規則列表
- **Create Coupon Trigger Rule**：創建新觸發規則

#### 8. **Surveys（問卷調查）**
- **Surveys List**：顯示所有問卷列表
- **Create Survey**：創建新問卷調查

### 主要用途

1. **會員獎勵管理**：創建和管理各類會員獎勵
2. **營銷活動配置**：設置優惠券、折扣卡等促銷工具
3. **遊戲化功能**：管理 Bingo、Stamps 等遊戲元素
4. **數據追蹤**：監控各資產的使用狀態和效果

## 注意事項

- 每種資產類型都有 List 頁面（查看現有資產）和 Create 頁面（創建新資產）
- 大部分資產需要設定有效期（Start Date 和 End Date）
- 部分資產支援 White Label App 和 Storellet App 分別顯示
- 詳細步驟請參考各資產類型嘅專門 model answer
