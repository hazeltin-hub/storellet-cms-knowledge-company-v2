## Model Answer

Brand 已確認嘅內容、推廣及 eShop 欄位如下：

- **Info URL (English)**｜選填｜建議／預設：URL｜用途：品牌資訊頁
- **Info URL (Local Language)**｜選填｜建議／預設：URL｜用途：中文品牌資訊頁
- **Short Description (English)**｜選填｜建議／預設：英文短描述｜用途：前台簡介
- **Short Description (Local Language)**｜選填｜建議／預設：中文短描述｜用途：前台簡介
- **Recommendation Dishes**｜選填｜建議／預設：推介菜式｜用途：顯示於 recommendation section
- **Message 1 / 2 / 3**｜選填｜建議／預設：品牌介紹文字｜用途：顯示於 brand description section 和用作SEO Header
- **Close Transaction Message Above / Below QR**｜選填｜建議／預設：/｜用途：POS / close transaction 顯示文案
- **Coupon Code Display Type**｜選填｜建議／預設：Member ID and Coupon ID｜用途：Coupon code 顯示邏輯
- **Stamp Only**｜選填｜建議／預設：No｜用途：是否 stamp only brand
- **Highlighted Image**｜選填｜建議／預設：圖片，建議 1MB｜用途：商店介紹圖片
- **Highlighted Image Description**｜選填｜建議／預設：圖片描述｜用途：對應 highlighted image
- **Eshop Banner**｜選填｜建議／預設：建議 3.2:1｜用途：eShop banner
- **Eshop Product ID**｜選填｜建議／預設：Stripe / Product ID｜用途：對應 eShop product
- **Promotion Message**｜選填｜建議／預設：推廣文案｜用途：前台推廣顯示
- **Promoted**｜選填｜建議／預設：Tick / Untick｜用途：是否標記 promoted
- **Carousel**｜選填｜建議／預設：YouTube / Image、Sort、URL｜用途：品牌頁 carousel
- **Brand Promo Web URL**｜系統產生 / 選填｜建議／預設：Auto URL｜用途：Merchant page URL
