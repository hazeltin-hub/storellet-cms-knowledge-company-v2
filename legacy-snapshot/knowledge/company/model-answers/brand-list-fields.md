## Model Answer

Brands List 會顯示以下系統產生資料：

- **Sequence**｜系統產生｜建議／預設：Auto｜用途：顯示brand 排序
- **ID**｜系統產生｜建議／預設：Auto｜用途：顯示Brand ID
- **Stamp Only**｜系統產生｜建議／預設：Auto｜用途：顯示是否stamp only
- **Brand Name**｜系統產生｜建議／預設：Auto｜用途：顯示所屬Brand
- **Group**｜系統產生｜建議／預設：Auto｜用途：顯示所屬Group
- **Company**｜系統產生｜建議／預設：Auto｜用途：顯示所屬Company
- **Join Date**｜系統產生｜建議／預設：Auto｜用途：顯示加入日期
- **Status**｜系統產生｜建議／預設：Auto｜用途：顯示Brand 狀態
