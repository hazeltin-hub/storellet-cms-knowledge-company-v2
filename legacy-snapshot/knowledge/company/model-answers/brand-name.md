## Model Answer

**Brand Name** 係 Create Brand 必填欄位，包含兩個部分：

### 欄位組成
- **Brand Name (English)**｜必填｜英文品牌名
- **Brand Name (Local Language)**｜必填｜中文品牌名

### 用途
- **主要用途**：所有平台都會顯示
- **功能**：品牌名稱會在 Storellet App、Branded App、Web 等所有平台顯示

## 注意事項

- Brand Name 用於 Brand 層級，唔同於 Company Name（公司內部用）和 Group Name（集團名稱）。
- Brand Name 是用戶在前台實際看到的品牌名稱，需要確保準確性和一致性。
- 需要同時填寫英文和中文版本。
