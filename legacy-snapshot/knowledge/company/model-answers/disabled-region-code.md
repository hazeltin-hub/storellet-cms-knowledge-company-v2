## Model Answer

**Disabled Region Code** 係 Create Company Group 選填 欄位。

### 用途
- **主要用途**：禁用電話地區碼
- **填寫要求**：選填欄位
- **建議填寫**：例如 86 / 853

## 注意事項

- 此欄位用於 Company Groups 層級。
