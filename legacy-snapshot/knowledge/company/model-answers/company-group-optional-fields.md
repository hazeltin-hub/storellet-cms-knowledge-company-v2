## Model Answer

Company Group 已確認為選填嘅欄位如下：

- **Registration Image (English)**｜選填｜建議／預設：註冊 / group 背景圖｜用途：註冊 / group 背景圖
- **Registration Image (Local Language)**｜選填｜建議／預設：註冊 / group 背景圖｜用途：註冊 / group 背景圖
- **Display Point Ratio**｜選填｜建議／預設：可留空｜用途：前台顯示用積分比例文字
- **Register Header Text (English)**｜選填｜建議／預設：留空｜用途：註冊頁 header text
- **Register Header Text (Local Language)**｜選填｜建議／預設：留空｜用途：中文註冊頁 header text
- **Registration Text (English)**｜選填｜建議／預設：留空｜用途：註冊頁說明文字
- **Registration Text (Local Language)**｜選填｜建議／預設：留空｜用途：中文註冊頁說明文字
- **Enable Master Brand**｜選填｜建議／預設：Tick / Untick｜用途：啟用 master brand 架構
- **Email Needed**｜選填｜建議／預設：Tick / Untick｜用途：是否要求會員 email
- **Unsubscribe when …**｜選填｜建議／預設：DELETED｜用途：退訂 / 刪除狀態邏輯
- **Group Description (English)**｜選填｜建議／預設：英文簡介｜用途：App / Web 描述
- **Group Description (Local Language)**｜選填｜建議／預設：中文簡介｜用途：App / Web 中文描述
- **Facebook**｜選填｜建議／預設：Facebook URL｜用途：關於： social link
- **Instagram**｜選填｜建議／預設：Instagram URL｜用途：關於： social link
- **Url**｜選填｜建議／預設：Website URL｜用途：關於： website link
- **About Us Url**｜選填｜建議／預設：About Us URL｜用途：About Us 連結
- **How To Use Url**｜選填｜建議／預設：How To Use URL｜用途：教學連結
- **EStore Url**｜選填｜建議／預設：E-shop URL｜用途：導向網店
- **Thumbnails**｜選填｜建議／預設：儲分示範圖｜用途：儲分示範
- **Disabled Region Code**｜選填｜建議／預設：例如 86 / 853｜用途：禁用電話地區碼
