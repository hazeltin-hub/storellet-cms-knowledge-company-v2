## Model Answer

Create Brand 嘅一般必填欄位如下：

- **Brand Name (English)**｜必填｜建議／預設：英文品牌名｜用途：所有平台都會顯示
- **Brand Name (Local Language)**｜必填｜建議／預設：中文品牌名｜用途：所有平台都會顯示
- **Brand Code**｜必填｜建議／預設：商戶名英文首字母｜用途：品牌代碼
- **Display Sequence**｜必填｜建議／預設：數字｜用途：控制APP/Web 顯示排序
- **Group**｜必填｜建議／預設：選擇所屬 group｜用途：品牌歸屬
- **Restaurant Category**｜必填｜建議／預設：餐廳類別｜用途：搜尋 / 分類用
- **Tag**｜必填｜建議／預設：品牌相關 keyword｜用途：APP search bar keywords
- **Geo Tag**｜必填｜建議／預設：地理 tag｜用途：APP 地區搜尋 / 分類
- **Brand Logo**｜必填｜建議／預設：400 x 400 (1:1) preserve 20% padding for logo and text to avoid cropping；建議 1MB｜用途：所有平台顯示 logo
- **Background Image on Dashboard**｜必填｜建議／預設：品牌背景圖 800 x 533 (1.5:1)，建議 1MB｜用途：App/Web 品牌頁 header 背景
- **Join Date**｜必填｜建議／預設：品牌開始日期｜用途：控制品牌有效期 / 顯示
- **Expiry Date**｜必填｜建議／預設：品牌到期日｜用途：控制品牌有效期
- **Max Point Earn Per Invoice**｜必填｜建議／預設：99999 / 按規則｜用途：每張單可賺最多積分
- **Max. Time of Earn Point per Day**｜必填｜建議／預設：999 / 按規則｜用途：每日可賺積分次數上限
- **Max. Time of Earn Point per Week**｜必填｜建議／預設：999 / 按規則｜用途：每週可賺積分次數上限
- **Max. Time of Earn Point per Day For POS**｜必填｜建議／預設：999 / 按規則｜用途：POS 每日賺分次數上限
- **Max. Time of Earn Point per Week For POS**｜必填｜建議／預設：999 / 按規則｜用途：POS 每週賺分次數上限
- **QR Code Expiry Day**｜必填｜建議／預設：-1 default （7日）｜用途：QR code 到期日
- **Background Colour 1**｜必填｜建議／預設：Brand color｜用途：App UI 色系
- **Text Colour 1**｜必填｜建議／預設：Brand color｜用途：App UI 文字色
- **Background Colour 2**｜必填｜建議／預設：Brand color｜用途：App UI 色系
- **Text Colour 2**｜必填｜建議／預設：Brand color｜用途：App UI 文字色
- **Background Colour 3**｜必填｜建議／預設：Brand color｜用途：App UI 色系
- **Text Colour 3**｜必填｜建議／預設：Brand color｜用途：App UI 文字色
- **Show Point Or Stamp on App**｜必填｜建議／預設：Yes｜用途：控制App 顯示積分 / 印花
- **Categories**｜必填｜建議／預設：Category tags｜用途：Web Category tags；Branded APP Tag 顯示
- **CusineTag**｜必填｜建議／預設：Cusine Tag｜用途：Web Category tags
- **Lower Price**｜必填｜建議／預設：價格range （最低）｜用途：價格range
- **Higher Price**｜必填｜建議／預設：價格range （最高）｜用途：價格range
- **Status**｜必填｜建議／預設：Active｜用途：控制 brand 狀態

另外 **Customer Service Email** 標示為「建議必填」，建議填寫 CS email，點擊後會導向 email app。
