## Model Answer

**Coupon Code Display Type** 係 Create Brand 選填 欄位。

### 用途
- **主要用途**：Coupon code 顯示邏輯
- **填寫要求**：選填欄位
- **建議填寫**：Member ID and Coupon ID

## 注意事項

- 此欄位用於 Brands 層級。
- 詳細設定請參考相應的 Create/Guide 文件。
