## Model Answer

**Shop Name** 係 Create Shop 必填欄位，包含兩個部分：

### 欄位組成
- **Shop Name (English)**｜必填｜英文分店名
- **Shop Name (Local Language)**｜必填｜中文分店名

### 用途
- **主要用途**：App 分店列表顯示
- **功能**：分店名稱會在 Storellet App 的分店列表中顯示

## 注意事項

- Shop Name 用於 Shop 層級，唔同於 Brand Name（品牌層）和 Group Name（集團層）。
- Shop Name 是用戶在 App 中看到的具體分店名稱，如「中環店」、「觀塘店」等。
- 需要同時填寫英文和中文版本。
