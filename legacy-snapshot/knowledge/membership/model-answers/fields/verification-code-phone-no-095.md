## Model Answer

**Phone No.** 係 Verification Code 嘅一個欄位。

### 欄位資訊

#### **基本資料**
- **欄位名稱**：Phone No.
- **功能模組**：Verification Code
- **欄位狀態**：查詢條件
- **建議填寫**：Enter phone no.

#### **主要用途**
搜尋該電話號碼對應 verification code

#### **注意事項**
會員註冊時驗證碼會發送到 mobile device
