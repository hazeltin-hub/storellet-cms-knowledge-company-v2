## Model Answer

**Brands** 係 Member 嘅一個欄位。

### 欄位資訊

#### **基本資料**
- **欄位名稱**：Brands
- **功能模組**：Member
- **欄位狀態**：操作欄位
- **建議填寫**：Select brand

#### **主要用途**
顯示 / 篩選會員 brand profile

#### **注意事項**
User Brand Profile will be shown if exists
