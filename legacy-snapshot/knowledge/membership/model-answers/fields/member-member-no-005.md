## Model Answer

**Member No.** 係 Member 嘅一個欄位。

### 欄位資訊

#### **基本資料**
- **欄位名稱**：Member No.
- **功能模組**：Member
- **欄位狀態**：顯示欄位
- **建議填寫**：System display

#### **主要用途**
顯示 Storellet 會員編號及 security code

#### **注意事項**
一般不需手動修改

## 使用場景

### 常見應用

- **會員資料**：與會員相關的資料顯示和管理
